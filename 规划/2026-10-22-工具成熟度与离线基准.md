# 工具成熟度与离线基准（长期参考）

撰写：2026-10-22。用于判断现有实现是否达到可暴露给 Controller/agent 的工具门槛；
结论会随新基准更新，不把一次基线固化成永久阈值。

## 1. 判定规则

工具必须先通过内部成熟度矩阵，才允许定义稳定 `ToolSpec`、进入 registry 或被
Controller 调用。未通过的工具只能保留为私有 adapter，不能计入策略训练 Trace。

| 工具 | 正确性 | 确定性 | 隔离性 | 延迟 | 成本 | 错误 observation | 版本语义 | 结论 |
|---|---|---|---|---|---|---|---|---|
| `paper_search` | ❌ Recall@50=0.469 | 🟡 依赖 dense/可选 rerank | ✅ 无 `answer_mode` | ❌ 平均 11.73s | ✅ 无生成调用 | ✅ 结构化失败 | ❌ 0.1，未注册 | 阻塞 |
| 全库覆盖/粗簇选择 | ❌ 46.59% nearest 候选 margin<0.02 | ✅ | ✅ | ✅ 全库约 3.7s | ✅ | 🟡 | ❌ | 阻塞 |
| `evidence_gate` | 🟡 fixture 5/5 | ✅ | ✅ | ✅ | ✅ | ✅ | ❌ | 可继续扩 fixture |
| `verify_claims` | 🟡 四态 fixture 4/4 | 🟡 规则确定性、LLM 非确定 | ✅ | ✅ | 🟡 | ✅ | ❌ | 可继续扩 fixture |
| `fetch_papers` | 🟡 只测离线 fixture | ✅ | ✅ | 待真实语料 | ✅ | ✅ | ❌ | 可继续扩 fixture |
| `candidate_filter` | ✅ fixture | ✅ | ✅ | 低 | ✅ | ✅ | ❌ | 可保留私有 adapter |
| `coarse_cluster_select` | ❌ 依赖未成熟覆盖 | ✅ | ✅ | 低 | ✅ | ✅ | ❌ | 阻塞 |
| `local_cluster` | ✅ 合成双簇 | ✅ 两次结果一致 | ✅ | 待真实规模 | ✅ | ✅ | ❌ | 可继续扩基准 |

标记：✅ 当前通过；🟡 部分通过或证据不足；❌ 未通过。

## 2. 全库覆盖基线

数据：meeting 语料 22,747 篇、71 个稳定簇。

| 指标 | 实测 |
|---|---:|
| 有归属论文 | 22,747 / 22,747（100%） |
| 稳定簇成员 | 2,396（10.53%） |
| 最近质心补归属 | 20,351（89.47%） |
| 未归属 | 0 |
| top1-top2 相似度 margin < 0.02 | 10,599（46.59%） |
| margin p10/p50/p90 | 0.0026 / 0.0188 / 0.0681 |
| top similarity p10/p50/p90 | 0.6841 / 0.7347 / 0.7926 |
| 最大簇占比 | 5.28% |
| 簇规模 p10/p50/p90 | 74 / 228 / 680 |

结论：几何上覆盖率为 100%，但大部分归属来自最近质心且近半 top1/top2 很难区分。
不能把 `assigned_coverage=1.0` 当成“粗簇质量已成熟”。阶段 2 仍未通过。

原始结果：`workspace/ledger/coverage_audit.json`。

## 3. `paper_search` 基线

固定查询：`eval/retrieval_questions.json`，共 7 条；模式 hybrid，Top-K=50。

| 指标 | 实测 |
|---|---:|
| Recall@10 | 0.1071 |
| Recall@20 | 0.2159 |
| Recall@50 | 0.4690 |
| Precision@10 | 0.0667 |
| nDCG@10 | 0.1272 |
| MRR | 0.2917 |
| 平均耗时 | 11.73s |

结论：当前只适合作为 provisional retriever，不足以冻结候选集/排序语义，也不能
直接成为 agent 的稳定工具。查询集只有 7 条，结果仅用于基线，不能据此做单题调参。

原始结果：`workspace/ledger/paper_search_tool_baseline.json`。

## 5. 当前门槛决定

- 不注册任何工具；`hotspot/harness` 仅内部使用。
- 不接 Controller，不把当前固定流程当 action trace。
- 最小纵链保留为
  `paper_search → evidence_gate → fetch_papers` 私有 adapter。
- `paper_search` 和全库覆盖修复前，P1 不得宣称完成，更不能进入 P2/P3。

## 6. P1 拆分进度

`subcluster_adaptive` 已接回以下私有 adapter：

- `paper_search`
- `candidate_filter`
- `coarse_cluster_select`
- `local_cluster`
- `evidence_gate`

集成冒烟（不调用生成模型）：

- Dreamer 事实路径：`evidence=answer`，候选过滤 64 → 64。
- offline RL 全局路径：得到 427 篇、16 个在线簇，策略进入
  `coarse_then_fine`，但覆盖选择回退 `weak_dominant_topic`。

结论：拆边界完成，不代表工具成熟。全局覆盖仍阻塞，最小纵链也因
`paper_search` 质量未通过而不能注册。
